# REQUIEM ATLAS
### Local-first OSINT and internet asset discovery dashboard

A standalone, educational MVP inspired by *the category* of Internet intelligence platforms, with original branding and interface. It is **not** Netlas, does not use Netlas datasets, and does **not** maintain an internet-wide search index.

## Features implemented

- Domain and globally routable IP validation.
- Passive DNS lookup for A, AAAA, MX, NS, TXT, CNAME, CAA.
- RDAP lookup (via `rdap.org`) and optional Certificate Transparency subdomain discovery (`crt.sh`).
- Optional, explicitly authorized direct HEAD and TLS checks (only on public addresses, no redirects, no crawling).
- DNS/infrastructure relationship graph.
- SQLite scan history, 7-day activity chart, search history and JSON/CSV exports.
- Responsive original dark interface in React + TypeScript.
- FastAPI API with built-in Swagger documentation at `http://127.0.0.1:8000/docs`.

## Requirements

- Windows 10/11, macOS or Linux; Python **3.11+** and Node.js **20.19+** or **22.12+** (recommended Node.js 22 LTS).
- Internet access for installing Python/JavaScript packages and querying public sources.

## Windows quick start

1. Extract the ZIP to a regular folder, e.g. `Desktop\requiem-atlas`.
2. Run **`start_windows.bat`** by double-clicking. It creates a Python virtual environment, installs backend and frontend dependencies, and launches two local development servers.
3. Open **http://127.0.0.1:5173** in your browser (the launcher will also try to open it).
4. Enter a domain such as `example.org` and click Analyze.

If PowerShell/Windows asks about unknown scripts, run the `.bat` file from a regular local directory. You can also use the manual steps below instead of changing system security settings.

## Manual start (all platforms)

**Terminal 1 / backend**:

```bash
cd backend
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

**Terminal 2 / frontend**:

```bash
cd frontend
npm install
npm run dev
```

URLs: **frontend** `http://127.0.0.1:5173`, **API** `http://127.0.0.1:8000/docs`.

## Architecture

```text
frontend/                  React + TypeScript + Vite
  src/App.tsx              UI, panels, graph, exports
  src/styles.css           responsive dark theme
backend/                   Python + FastAPI
  app/main.py              HTTP endpoints
  app/scanner.py           passive discovery + guarded probes
  app/db.py                SQLite persistence
  tests/test_api.py        unit/integration tests
start_windows.bat          launch both development servers
start_unix.sh              macOS/Linux launch helper
```

`backend/app/db.py` stores scans in `data/atlas.sqlite3`, automatically created on first boot.

### API endpoints

| Method | Path | Function |
| --- | --- | --- |
| GET | `/health` | API health |
| GET | `/api/stats` | Dashboard stats |
| GET | `/api/history` | Recent records; supports `?q=...` |
| GET | `/api/history/{id}` | Full archived result |
| POST | `/api/analyze` | Run bounded lookup |

Example:

```json
{"target":"example.org","authorized_probe":false,"include_ct":false}
```

`authorized_probe: false` by default. To directly contact the target web server, check the explicit authorization box. Only use it for assets you own or have permission to test. The feature uses a pinned globally-routable IP and never follows HTTP redirects. **No port sweeping, brute-force, exploits or CVE claims.**

## Limitations

- This MVP performs **on-demand lookup**. It is not a Netlas-scale, historical index or a continuous scanner.
- Passive lookups can fail due to DNS, RDAP providers, availability/rate limits or firewalls. Failed providers produce empty sections or notes; they are not interpreted as security findings.
- CT subdomain enumeration is optional and capped at 60 names.
- The graph includes observed relationships, not a proof of organizational ownership.
- DNS results can contain data generated by third parties; treat them as untrusted.
- The local database is unencrypted, so do not store sensitive investigations on shared PCs.
- This local development build has **no login/authentication**: do not expose its API to a public network.
- SQLite is deliberately used to make the initial version run without Docker. Planned upgrades include PostgreSQL, OpenSearch, scheduled opt-in monitoring, user accounts and larger datasets.
