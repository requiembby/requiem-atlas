# Requiem Atlas — инструкция на русском

Это первая **рабочая версия** нашего поисковика по публичной интернет-инфраструктуре. Внутри не картинка, а сервер на Python, интерфейс на React и локальная база SQLite.

## Как запустить на Windows 11

**Первый запуск требует интернет**, установленный Python 3.11+ и Node.js 22 LTS.

1. Распакуй `requiem-atlas.zip` на рабочий стол. Внутри будет папка `requiem-atlas`.
2. Открой папку и **дважды нажми `start_windows.bat`**.
3. Откроются два окна терминала: сервер Python и интерфейс React. **Не закрывай их**, пока пользуешься приложением.
4. В браузере зайди на **http://127.0.0.1:5173**.
5. Введи `example.org` или любой другой публичный домен. Запусти анализ.
6. Результат автоматически сохранится в разделе «История запросов».

**Если Windows пишет «Python/Node/npm не найден»**, сначала установи:
- Python: https://www.python.org/downloads/ (отметь «Add python.exe to PATH» во время установки).
- Node.js LTS: https://nodejs.org/en/download

После установки открой новую папку/терминал и снова запусти `start_windows.bat`.

## Как устроен анализ

- **DNS:** A, AAAA, MX, NS, TXT, CNAME, CAA.
- **RDAP:** публичная информация о регистрации домена или IP-блоке.
- **CT:** необязательный поиск поддоменов в публичных журналах сертификатов.
- **HTTP/TLS:** необязательная проверка заголовков и HTTPS. **Включай только для принадлежащих тебе или разрешённых целей.**
- **Граф:** визуальные связи между целью, DNS-узлами и поддоменами.
- **Экспорт:** JSON со всеми данными, CSV с DNS-записями.

По умолчанию приложение ничего не сканирует напрямую на чужих серверах; используются открытые источники данных. Режим прямых проверок включается отдельной галочкой. Нет сканирования всех портов, массового обхода и поиска эксплойтов.

## Что появится в следующих версиях

PostgreSQL и OpenSearch для масштабирования, периодическое обновление разрешённых активов, расширенные фильтры, авторизация пользователей и более сложная визуализация.

## Если не открывается

- **`http://127.0.0.1:8000/health`** показывает `{"status":"ok",...}`? Значит Python-сервер работает.
- **`http://127.0.0.1:5173`** показывает интерфейс? Значит Node.js запущен.
- Ошибка `npm`? Проверь интернет и что установлена версия Node.js 22 LTS.
- Ошибка `pip`? Проверь интернет и Python 3.11+.
- DNS/RDAP пустые? Публичные сервисы иногда блокируют запросы; попробуй другой домен.

**Важно:** приложение предназначено для собственного компьютера. Не открывай порты 8000 и 5173 в интернет.

## Опубликовать проект на GitHub

Если репозиторий ещё не создан, можно создать его и загрузить код одним скриптом:

1. Установи [Git for Windows](https://git-scm.com/downloads/win) и [GitHub CLI](https://cli.github.com/).
2. В распакованной папке `requiem-atlas` запусти `publish_github_windows.bat`.
3. Если необходимо, GitHub CLI откроет вход через браузер. Скрипт проверяет, что вход выполнен в аккаунт `requiembby`.
4. Скрипт создаст **публичный** репозиторий `requiembby/requiem-atlas`, отправит исходный код и откроет страницу репозитория.

Не выкладывай файл базы данных, `.env`, ключи или токены. Они исключены через `.gitignore`.

**Скриншоты в `docs/`:** визуальные предпросмотры, построенные по стилям и структуре приложения. Экран с результатами использует **демонстрационные данные**, а не результаты живого сетевого анализа.
